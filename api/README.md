# api

Veuillez utiliser un environnement virtuel python nommé venv :

```
python -m venv venv
```

```
.\venv\Scripts\activate
```

## Installer :

```
pip install -r .\requirements.txt
```

## Lancer :

```
uvicorn app.main:app --reload
```

## Accéder au Swagger :

```
http://127.0.0.1:8000/docs
```
